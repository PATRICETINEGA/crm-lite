# CRM Lite

Lightweight CRM for contacts and deals.

## Features
- Authentication
- Contacts
- Deals with stages and value
- Dashboard summary
- Seed data

## Tech
Next.js 14 · Prisma · SQLite · NextAuth · Tailwind

## Setup
```bash
npm install
npx prisma generate
npx prisma db push
npm run db:seed
npm run dev
```
